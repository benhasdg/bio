Turning Web Analytics Into Decisions at UAB

At UAB I manage web platforms for four different departments, which means more than just keeping sites online. I set up Google Tag Manager and Looker Studio to track how people actually use them—what they search for, where they drop off, which pages turn into service requests.

That data now drives what gets worked on: which pages get rebuilt, which flows get simplified, and where the actual friction is instead of where we assumed it was.
